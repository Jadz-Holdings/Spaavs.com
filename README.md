# SPAAVS.com

Corporate website for **SPAAVS — Smart Parking & Autonomous Vehicle Services**.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Development

```bash
npm install
npm run dev
```

## Notes

- Default theme: Tiffany Blue/Green Chrome
- Logo wordmark and tagline are separate brand assets
- Company status: In Development

See `docs/SPAAVS_MEMORY.md` for design/content memory pointers.
